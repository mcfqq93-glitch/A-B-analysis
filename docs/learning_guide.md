## 1. A/B 测试的整体流程

```
业务问题 → 定义指标与假设 → 功效分析定样本量 → 随机分流上线
        → 数据质量检查（SRM 等） → 统计检验 + 置信区间 → 稳健性检查
        → 分群分析（预先声明的） → 业务决策与复盘
```

**为什么要做 A/B 测试，而不是直接比较"上线前 vs 上线后"？**
上线前后的对比会混入季节、促销、竞品活动等因素。**随机分组**让两组除了"看到的页面"以外在所有方面（包括我们观测不到的因素）期望上相同，所以两组的差异可以被**因果地**归因于页面改动。这是 A/B 测试的根本价值。

**本项目对应**：业务问题是"新落地页是否提高转化率"；指标是用户层面的转化率；随机化单位是用户。

## 2. 假设检验的基本概念

| 概念 | 含义 | 本项目 |
|---|---|---|
| 原假设 H₀ | 默认"没有效果"的假设 | p_new = p_old |
| 备择假设 H₁ | 我们想找证据支持的假设 | p_new ≠ p_old |
| 检验统计量 | 把"差异"标准化成一个数，衡量差异是噪声的几倍 | z |
| p 值 | **假如 H₀ 为真**，看到至少这么极端结果的概率 | 0.19 |
| 显著性水平 α | 预先设定的假阳性容忍度 | 0.05 |
| 第一类错误（α） | H₀ 为真却拒绝它（假阳性） | 把没用的页面上线 |
| 第二类错误（β） | H₁ 为真却没拒绝 H₀（假阴性） | 错过一个好页面 |
| 功效 1-β | H₁ 为真时检测出来的概率 | 设计为 0.8 |

**最常被问的问题：p 值是什么？**
> p 值是在原假设成立的前提下，得到当前观测结果或更极端结果的概率。p 值小，说明"如果真的没效果，这个结果会很罕见"，所以我们倾向于怀疑原假设。

**p 值不是什么：**
- 不是"原假设为真的概率"。
- 不是"结果是偶然的概率"。
- 不衡量效果的大小。样本足够大时，一个微不足道的差异也可以有极小的 p 值。

**"不显著"不等于"没有效果"**，它只代表证据不足。要论证"没有重要的效果"，需要看置信区间是否已经排除了业务上重要的取值（见第 7 节）。

## 3. 数据质量与 SRM 检验

### 是什么
SRM（Sample Ratio Mismatch，样本比例失衡）指实际分流比例显著偏离设计比例，例如设计 50/50，实际是 50.8/49.2。

### 为什么用
SRM 说明实验系统有 bug，某一类用户在某一组里**被系统性地丢掉或多算**。这时两组不再可比，任何效果估计都可能有偏差。微软、LinkedIn 等公司的经验是：大约 6%–10% 的实验会出现 SRM。它是成本最低、最有价值的一项检查。

### 怎么算：卡方拟合优度检验
$$\chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i}, \quad df = k - 1$$
- $O_i$：第 i 组的实际人数；$E_i$：总人数 × 设计比例。

### 怎么解读
- 阈值通常取 **p < 0.001**（比 0.05 严格），因为样本大时检验很敏感，而且每个实验都会做这项检查，需要控制误报。
- 本项目：145,274 vs 145,310，p = 0.95 → 没有 SRM。

### SRM 常见原因
- 新版本页面加载更慢 / 崩溃，导致实验组的埋点事件丢失。
- 重定向实现方式不同导致一组用户流失。
- 机器人流量被某一组的过滤规则过滤掉。
- 实验进行中修改了分流比例。
- 数据清洗规则对两组有不同的影响。

### 本项目还做了哪些数据质量检查
1. **组别与页面错配**（3,893 行）：用户被分到 control 却看到 new_page。由于两组错配数量对称（1,928 vs 1,965），直接删除。如果错配只发生在一组，应考虑 ITT（意向处理）分析。
2. **重复用户**（1 个）：违反"每个观测独立"，保留首次曝光。
3. **协变量平衡**：检查国家分布在两组中是否一致（卡方独立性检验，p = 0.41）。

## 4. 功效分析与样本量

### 是什么
在实验**开始前**回答："要多少样本，才能以足够高的概率检测到我们关心的效果？"

### 四个输入与直觉
| 输入 | 对样本量的影响 | 直觉 |
|---|---|---|
| 基线转化率 p₁ | p 越接近 0.5，方差 p(1-p) 越大，需要越多样本 | 噪声大小 |
| MDE δ | **n ∝ 1/δ²** | 信号大小 |
| α | α 越小，需要越多样本 | 对假阳性的容忍度 |
| 功效 1-β | 越高，需要越多样本 | 对假阴性的容忍度 |

### 公式（两组等量时，每组样本量）
$$n = \frac{\left(z_{1-\alpha/2}\sqrt{2\bar p(1-\bar p)} + z_{1-\beta}\sqrt{p_1(1-p_1)+p_2(1-p_2)}\right)^2}{\delta^2}$$

常用的简化记忆版本（α=0.05、功效=0.8）：
$$n \approx \frac{16\,\sigma^2}{\delta^2}, \quad \sigma^2 = p(1-p)$$
"16" 来自 $2 \times (1.96 + 0.84)^2 \approx 15.7$。面试时能快速估算是加分项：基线 12%，相对提升 5%（δ = 0.006）→ n ≈ 16 × 0.1056 / 0.000036 ≈ 4.7 万/组，与精确计算一致。

### 怎么解读
- 本项目日均约 1.26 万用户：检测 5% 相对提升需每组约 4.7 万人（约 7–8 天）；检测 1% 相对提升则需每组约 115 万人（半年），不现实。
- **反向使用（MDE）**：给定实际样本量，能检测的最小效果是多少？本项目每组约 14.5 万人 → MDE ≈ 0.34pp（相对 2.8%）。

### 常见错误
- **不做功效分析就开跑**，结果不显著时无法区分"真的没效果"和"样本不够"。
- **事后功效（post-hoc power）**：用观测到的效应量计算功效，它和 p 值一一对应，没有新信息。
- 只跑到样本量达标就停，**没覆盖完整周期**（至少一周）。

## 5. 双比例 z 检验

### 是什么
比较两组转化率是否相同的标准方法。

### 前提假设
1. 随机分组（两组可比）。
2. 观测之间独立；两组之间没有相互影响（SUTVA，例如社交网络中的实验通常不满足）。
3. 样本足够大：每组的 $np$ 和 $n(1-p)$ 都至少 10，此时根据中心极限定理，样本比例近似正态。

### 怎么算
$$\hat p = \frac{x_c + x_t}{n_c + n_t}, \qquad SE_0 = \sqrt{\hat p(1-\hat p)\left(\tfrac{1}{n_c}+\tfrac{1}{n_t}\right)}, \qquad z = \frac{\hat p_t - \hat p_c}{SE_0}$$
双侧 p 值 $= 2(1 - \Phi(|z|))$。

**为什么用合并比例（pooled）？** 检验是在"H₀ 为真"的前提下进行的，H₀ 认为两组转化率相同，所以用两组合并的数据估计这个共同的转化率最准确。

### 怎么解读（本项目）
- p_c = 12.04%，p_t = 11.88%，差 −0.16pp，z = −1.31，p = 0.19 → 不能拒绝 H₀。

### 与 t 检验的关系
对于 0/1 数据，样本均值就是转化率，Welch t 检验在大样本下给出几乎相同的结果。z 检验是比例数据的"标准答案"，t 检验更通用（收入、时长等连续指标）。

## 6. 卡方检验

### 两种卡方检验，别混淆
| | 拟合优度检验 | 独立性检验 |
|---|---|---|
| 问题 | 观测分布是否符合预期分布？ | 两个分类变量是否独立？ |
| 本项目用途 | **SRM 检验** | 转化 vs 组别；国家 vs 组别 |
| 自由度 | k − 1 | (r − 1)(c − 1) |

### 与 z 检验的关系
对 2×2 表（不做连续性校正），**χ² = z²**，p 值完全相同。本项目：χ² = 1.7185 = (−1.311)²。
- z 检验的优点：有方向，可以单侧，直接给出差值。
- 卡方检验的优点：可以推广到多组（A/B/C/D）和多类别结果。

### 期望频数要求
每个格子的期望频数应 ≥ 5，否则用 Fisher 精确检验。

## 7. 置信区间

### 为什么比 p 值更重要
p 值只回答"有没有差异"，置信区间同时回答"差异大概多大"和"有多不确定"。业务决策需要的是后者。

### 绝对差的 CI（Wald，非合并 SE）
$$(\hat p_t - \hat p_c) \pm z_{1-\alpha/2}\sqrt{\frac{\hat p_c(1-\hat p_c)}{n_c} + \frac{\hat p_t(1-\hat p_t)}{n_t}}$$
**为什么这里不用合并比例？** 估计区间时不再假设 H₀，两组各自的方差应分别估计。

### 相对提升的 CI（Delta 方法）
业务方习惯听"提升了 x%"。相对提升 $p_t/p_c - 1$ 是比值，分母 $p_c$ 也有误差，所以不能直接把绝对差的区间除以 $p_c$。
对 $g(p_t, p_c) = \log(p_t/p_c)$ 做一阶泰勒展开（Delta 方法）：
$$\operatorname{Var}[\log(\hat p_t/\hat p_c)] \approx \frac{1-p_t}{n_t\,p_t} + \frac{1-p_c}{n_c\,p_c}$$
在对数尺度上求区间，再取指数减 1。

**Delta 方法的一般形式**：若 $\hat\theta$ 近似正态，则 $g(\hat\theta)$ 的方差 $\approx g'(\theta)^2 \operatorname{Var}(\hat\theta)$（多元时为 $\nabla g^\top \Sigma \nabla g$）。它在 A/B 测试里还常用于**比率指标**（如人均点击 = 总点击/总用户，分子分母都是随机变量）。

### 怎么解读（本项目）
- 绝对差 95% CI：[−0.39pp, +0.08pp]；相对提升 95% CI：[−3.24%, +0.66%]。
- 包含 0 → 不显著（与 p = 0.19 一致）。
- 上界仅 +0.66%：即使新页面有正面效果，最多也只有约 0.66% 的相对提升 → **业务上不值得**。

### 正确表述
> "如果我们用同样的方法反复做实验，95% 的区间会覆盖真实差值。"
> 不要说"真实差值有 95% 的概率落在这个区间里"（频率学派中真实值是固定的，这是贝叶斯可信区间的解读）。

## 8. Bootstrap 与置换检验

### Bootstrap（自助法）
**是什么**：通过从样本中**有放回**地重抽样，模拟"如果重新做一次实验"统计量的分布。
**怎么做**：
1. 从对照组有放回地抽 $n_c$ 个，从实验组有放回地抽 $n_t$ 个（**分组各自抽**，因为分组是固定的设计）。
2. 计算差值。
3. 重复 B 次（如 10,000 次），取 2.5% 与 97.5% 分位数作为 95% CI（百分位法）。

**什么时候真正有用**：指标偏态严重（收入）、样本小、统计量没有简单的方差公式（中位数、分位数、比率指标）。本项目里 Bootstrap 和 z 检验结果几乎一样，说明正态近似很好，这本身就是一个有价值的稳健性结论。

**实现技巧**：0/1 数据有放回抽 n 个再求和 ≡ 从 Binomial(n, p̂) 抽一个数。这样 10 万次 Bootstrap 也只需不到一秒。

### 置换检验（Permutation test）
**思想**：H₀ 为真时，"组别标签"对结果没有影响，可以随意交换。
**怎么做**：把所有用户混在一起，随机重新分配标签（保持两组人数不变），计算差值；重复很多次，得到 H₀ 下差值的分布。p 值 = 置换差值的绝对值 ≥ 观测差值绝对值的比例。
**技巧**：打乱标签后实验组的转化数服从超几何分布，可以直接抽样。

### 两者的区别
| | Bootstrap | 置换检验 |
|---|---|---|
| 主要产出 | 置信区间 | p 值 |
| 模拟的世界 | 真实世界（H₁ 也可能成立） | H₀ 成立的世界 |
| 抽样方式 | 组内有放回 | 跨组打乱标签（无放回） |

## 9. CUPED 方差缩减

### 是什么
CUPED（Controlled-experiment Using Pre-Experiment Data，微软 Deng et al. 2013）利用实验**前**的数据，减去指标中"可以被预测的部分"，从而降低方差。

### 为什么用
方差小 → 标准误小 → 同样的样本量能检测到更小的效果，或者用更少的样本 / 更短的时间得到结论。在大公司里，这直接等价于"实验跑得更快"。

### 怎么算
$$Y^{cuped}_i = Y_i - \theta(X_i - \bar X), \qquad \theta = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}$$
- $X$：同一用户在实验前的同类指标（如实验前两周的收入）。
- $\theta$：用两组合并的数据估计，等价于 Y 对 X 的回归斜率。

### 为什么无偏
$X$ 在实验之前就确定了，不受处理影响；随机分组保证 $E[\bar X_t] = E[\bar X_c]$。因此调整项在两组间的期望差为 0，效果估计的期望不变。

### 方差减少多少
$$\operatorname{Var}(Y^{cuped}) = \operatorname{Var}(Y)(1 - \rho^2)$$
推导：$\operatorname{Var}(Y - \theta X) = \operatorname{Var}(Y) - 2\theta\operatorname{Cov}(X,Y) + \theta^2\operatorname{Var}(X)$，对 θ 求导令其为 0 得到 $\theta^* = \operatorname{Cov}/\operatorname{Var}(X)$，代回得 $\operatorname{Var}(Y)(1-\rho^2)$。

ρ = 0.5 → 方差减少 25%；ρ = 0.7 → 49%；ρ = 0.9 → 81%。

### 和回归的关系
CUPED 的结果与线性回归 $Y = \alpha + \tau \cdot \text{treatment} + \beta X$ 中 τ 的估计几乎相同（即 ANCOVA）。notebook 03 中两者都是 0.164。

### 本项目的结果（模拟数据）
- ρ = 0.76 → 方差减少 57%，SE 缩小 35%，等价样本量 ×2.35。
- 朴素估计 p = 0.51（检测不到真实存在的 +3% 效果），CUPED 后 p = 0.007。
- 400 次重复模拟：两种方法都无偏，CUPED 的功效从 21% 升到 41%。

### 注意事项
- 协变量**必须不受处理影响**，用实验期间的数据会导致偏差。
- 新用户没有历史数据：可以把 X 设为 0，加一个"是否有历史数据"的指示变量；或用其他实验前特征。
- 对转化率这种 0/1 指标同样适用，协变量可以是"实验前是否购买过"。

### 为什么本项目用模拟数据
Udacity 数据集没有用户实验前的行为数据，无法诚实地应用 CUPED。在面试中要**主动说明**这一点，这比悄悄"造"一个协变量更能体现严谨性。

## 10. 分群分析与多重比较校正

### 为什么要做分群
整体效果可能掩盖了分群间的差异（异质性处理效应，HTE）。例如新页面可能对移动端用户有效，对桌面端用户有害。

### 为什么危险：多重比较
做 m 个独立检验，至少一个假阳性的概率是 $1-(1-\alpha)^m$：
| m | 1 | 3 | 5 | 10 | 20 |
|---|---|---|---|---|---|
| FWER | 5% | 14% | 23% | 40% | 64% |

### 三种校正方法
**Bonferroni**：$p_{adj} = \min(m \cdot p, 1)$。简单，最保守。

**Holm（逐步降低法）**：
1. 把 p 值从小到大排序：$p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}$。
2. 第 k 个乘以 $(m-k+1)$。
3. 取累计最大值以保证单调。

同样控制 FWER，但**总是至少和 Bonferroni 一样有功效**，所以没有理由用 Bonferroni 而不用 Holm。

**Benjamini–Hochberg（BH）**：
1. 排序后第 k 个乘以 $m/k$。
2. 从大到小取累计最小值。

控制 **FDR**（显著结果中假阳性的比例），功效更高。适合探索性分析（例如同时看 50 个次要指标），找到的结果再用新实验验证。

### FWER 和 FDR 怎么选
- 确认性结论、错一次代价很大（决定上线）→ 控制 FWER（Holm）。
- 探索性筛选、后续还会验证 → 控制 FDR（BH）。

### 交互作用检验
"美国显著、英国不显著" **不能**推出"效果在美国和英国不同"。正确做法是检验交互项：
$$\operatorname{logit}P(Y=1) = \beta_0 + \beta_1 T + \gamma\,\text{country} + \delta\,(T\times\text{country})$$
用似然比检验 H₀: δ = 0。本项目 LR = 2.47，df = 2，p = 0.29 → 效果在各国之间没有显著差异。

### 辛普森悖论
各分群都显示 A 比 B 好，合并后却 B 比 A 好。原因通常是分群在两组中的占比不同。随机实验中两组的分群构成期望上相同，所以较少发生；但如果出现 SRM 或者分流比例随时间变化，就可能出现。

### 最佳实践
- **事先声明**要分析的分群（如平台、新老用户、国家）。
- 报告所有做过的分群，而不只是显著的那个。
- 事后发现的分群效应只能作为新假设，用新实验验证（避免 HARKing）。

## 11. 偷看问题与序贯检验

### 问题
每天看一次 p 值，一旦 < 0.05 就停 → 假阳性率远超 5%。本项目模拟中看 20 次后假阳性率达到 **23%**。

### 原因
H₀ 为真时，p 值随着数据累积而上下波动（随机游走），看的次数越多，越有可能在某一次碰巧跌破 0.05。

### 解决办法
1. **固定样本量设计**：事先确定样本量，中途只做健康检查（SRM、bug、护栏指标），不根据主要指标停实验。
2. **成组序贯检验（Group sequential）**：预先规定看几次，用 α 消耗函数（如 O'Brien–Fleming：早期门槛极严，后期接近 1.96）分配每次的显著性水平。
3. **始终有效推断（Always-valid inference / mSPRT）**：如 Optimizely 的统计引擎，可以随时看。
4. **贝叶斯方法**也需要预先确定停止规则，不能完全免除这个问题。

## 12. 从统计结果到业务决策

### 决策矩阵
| | 业务上有意义 | 业务上无意义 |
|---|---|---|
| 统计显著 | 上线 | 效果真实但太小，权衡成本 |
| 统计不显著 | 样本不足，考虑延长实验 | **不上线（本项目）** |

### 决策时还要看什么
- **护栏指标（Guardrail metrics）**：页面加载时间、退款率、客诉等不能变差。
- **新奇效应 / 变化厌恶**：看效果随时间的趋势，必要时延长实验或只分析新用户。
- **长期效应**：短期转化提升可能以长期留存为代价，可以设置长期 holdout 组。
- **实施成本与风险**：开发、维护、回滚成本。

### 本项目的结论（可以直接在面试中复述）
> 我分析了一个约 29 万用户的电商落地页 A/B 测试。先做了数据质量检查：删除了 1.3% 组别与页面错配的记录和重复用户，SRM 检验 p = 0.95，国家分布平衡。主分析用双比例 z 检验，新页面转化率 11.88%，旧页面 12.04%，差值 −0.16 个百分点，95% 置信区间 [−0.39, +0.08]，p = 0.19，不显著。实验的 MDE 约 0.34 个百分点，功效充足；置信区间上界只对应 0.66% 的相对提升，已经排除了有业务意义的正面效果。Bootstrap 和置换检验结果一致；分国家分析经 Holm 校正后均不显著，交互项检验也不显著。所以我建议不上线新页面。另外我用模拟数据演示了 CUPED，在相关系数 0.76 时方差降低了 57%，相当于样本量翻倍以上。
